## طريقة الاستخدام

1. افتح ملف `index.html` في أي متصفح حديث (Chrome / Edge / Firefox / Safari)
2. أو ارفعه على GitHub Pages / Netlify / Vercel / أي استضافة ثابتة
3. ابدأ بإضافة الحيوانات من زر **حيوان جديد**
4. استخدم البحث برقم الحيوان لفتح بطاقته الكاملة فوراً
5. زر **🖨 طباعة** متوفر في الشريط العلوي + داخل بطاقة كل حيوان + صفحة التقارير

### الوصول من أي جهاز + التحديث التلقائي

- ارفع المشروع على **GitHub Pages** → يصبح لديك رابط ثابت تفتحه من الموبايل أو أي كمبيوتر.
- كلما عدّلت الملفات وعملت `git push` يتحدث النظام تلقائياً لكل من يفتح الرابط.
- **البيانات** حالياً محفوظة محلياً في متصفح كل جهاز.
  - لنقل البيانات بين الأجهزة: استخدم **تصدير JSON** من جهاز → **استيراد** في الجهاز الآخر.
  - للمزامنة السحابية الحقيقية لاحقاً يمكن إضافة Firebase / Supabase (مجاني).

### رفع على GitHub Pages

```bash
git init
git add .
git commit -m "نظام إدارة مزرعة المجترات - د.م/ أيمن زغلول"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

ثم من إعدادات المستودع → **Pages** → اختر فرع `main` → Save.  
الرابط سيكون بالشكل: `https://USERNAME.github.io/REPO/`
